Key decisions (see the handover for the full map):
- The server imports apps/sot-engine.js directly — one engine everywhere.
- Auth-lite: random playerToken server-side; clients PROPOSE their id so
  engine state matches on both sides (eligibility is id equality).
- Groups are StoredSotGroup supersets → SotCommandBus runs server-side on
  the same objects (POST /sot/groups/:code/cmd = one brain for bots + app).
- Cloud-bound local mirrors never auto-open their next battle; the poll
  merge follows the server day (engine.js guard on g.cloud).
- Conflict rule: server wins + toast; offline keeps queueing (replay pushes
  to the API on reconnect).
