## Fixes made in this session (the prior session's app was ~90% but broken)

1. **`app.js:126` syntax error** (unbalanced paren in the welcome screen —
   the app didn't parse at all).
2. **Engine-wait race**: headless chromium intermittently ran `app.js`
   before `engine.js` finished fetching → "engine failed to load". `app.js`
   now waits (dynamic import + 100ms poll, ≤10s) for `window.RWFSoT`.
3. **`seedDemo` never set `state.onboarded`** → render()'s onboarding guard
   bounced the demo jump straight back to welcome.
4. **Same-day battle records collided**: demo sprints compress a season into
   minutes; `recordBattleDay` keys by date and *throws* on duplicates, so
   battle 2's points silently never recorded. `dateLabel(b, s)` now suffixes
   `#idx` on collision (the season calendar renders battle rows, never this
   internal key — UI unaffected).
5. **Bomb mirror race**: mirror `atMs` used a second `Date.now()` (could
   differ 1ms from the core's `issuedAt` → defused/fizzled never synced).
   Now derived exactly: `r.deadline − SURPRISE_BOMB_WINDOW_MS`.
6. **Timed entry**: START didn't re-render (button never flipped to STOP)
   and re-render reset the display to 00:00 — now renders live elapsed.
7. **Close-call tightened to <5%** of target (was 10%) per the brief.
8. **Canvas→PNG win card** (Gold Arcade styled, Anton via @font-face) on the
   YOU WON overlay; dataURL exposed at `window.rwfLastSharePng` for e2e.
9. **e2e harness robustness**: unique CDP port per run + kill-on-exit (a
   thrown failure used to orphan chromium → next run bound to the stale
   devtools endpoint → flaky "v4 app load"); language gate now scans quoted
   UI strings (interpolations stripped) instead of raw source (code
   identifiers like `e.ruf` and engine comments aren't UI copy); the one
   real UI offender ("bonus RUF" in the combo_boost detail) reworded.

## e2e (apps/sot/e2e.mjs) — 120/120, zero console errors

`bun apps/sot/e2e.mjs` (self-contained: Bun server + headless chromium CDP,
390×844@2x; shots → `apps/sot/shots/*_sot.png`).
Journey: onboard → create wizard (individual · Mon+Tue · 200 · sprint clock ·
weekly · charity $10+5%) → battle home → **Rep Steal** (pure gain verified in
state) → **quick log** (preset → confirm → success/remaining → UNDO → keypad)
→ **TIMED ENTRY** (plank: START HOLD, real 11s, STOP → confirm in secs →
logged) → **first-to-target DAILY WIN** (confetti + PNG card) → rival **banks**
→ deadline → third player **fails** → recap → season hub (1:1 points, pot
math, fee) → day 2: **Surprise Bomb HIT** (defused, +20 bonus) + **MISS**
(fizzled, target stays — engine semantics; the fuse is a real 10-min window,
the e2e time-travels ONE bomb's deadline via the exposed core to resolve the
fizzle through the genuine `resolveExpiredBombs` path) → **Lightning ×3**
(full-screen storm, ×3 verified on a real log) → second Daily Win → season
ends → **SEASON CHAMPION** → winner-chooses **charity** ($38 of $40, $2 fee,
receipt) → feed reaction + profile stats → **join flow** as a second player
(code → preview → stake agreement) → desktop 1280 no-overflow →
reduced-motion → language gates (UI strings + every screen swept at runtime)
→ console gate.

Deterministic-card note: the daily drop is RNG, so the e2e grants Jack his
second bomb through `RWFSoT.engine.grantPowerUp` (the same exposed core the
app drives) and passes full card ids (`'surprise_bomb'`, not the `'bomb'`
alias — `activateCard` doesn't alias).
