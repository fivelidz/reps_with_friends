## Gotchas hit

- **A same-URL hash `Page.navigate` does NOT create a new document** —
  chromium treats it as a hashchange, so the SPA just re-renders and
  `__plays`/module state carry over. For persistence tests use
  `location.reload()` (the SFX probe's first "reload" assertion was
  reading stale counters until this was fixed).
- **A throwaway script whose pkill pattern matches its own path kills its
  own bash wrapper** (silent death, no exit code printed). Match on
  `remote-debugging-port=NNNN` instead of the script name.
- The v3 log sheet opens instantly behind the still-animating draft
  sheet; the draft's 520ms timeout then `closeSheet(true)`s whatever
  sheet is current. Wait for `.bd-sheet` to be GONE after Keep before
  driving the log sheet (both suites now do).
- The hub's old `class="grid"` div in the versions section was NEVER
  styled in hub.css (the two cards shipped stacked full-width) — now
  `cards cards--3`.
- Concurrent-lane traffic in the tree right now: apps/avatars, apps/booth,
