## Shipped (this session)

1. **`apps/v3/course.js` — reduced-motion runner freeze (REAL BUG, fixed).**
   Under `prefers-reduced-motion: reduce`, the render loop calls
   `_step(0, now)` so the dirty-gate can render without an animation clock —
   but `ease = 1 − e^(−dt·2.4)` with dt=0 is **0**, so `r.t` never converged:
   runners were frozen at the start line forever (log reps → nothing moves).
   Fix: `const ease = this.reduced ? 1 : 1 − Math.exp(−dt·2.4)` — reduced
   motion now SNAPS the runner to its target (static = correctly positioned,
   no glide, not frozen). Verified by a dedicated headless probe (below).
2. **`apps/v3/daily.js` — header comment tidy.** The inherited v2 banner
   referenced the board app's "RACE CLOCK … lap counter"; rewritten in battle

3. **Dev server restarted** (kill stale pid → fresh `bun serve.ts`, nohup,

## Gotchas hit

- **Stale dev server**: `bun serve.ts` holds routes in memory — after ANY
  serve.ts route change, kill + restart or you'll chase phantom 500s/404s
  (symptom: `/v3` serving the main site's HTML). Check with
  `curl localhost:4173/v3/ | rg <title>`.
- **`Emulation.setEmulatedMediaFeatures` doesn't exist** in this chromium
  build — the correct CDP method is `Emulation.setEmulatedMedia` (params
  shape unchanged).
- **A concurrent themes-lane agent was writing `design/` during this
  session** (fonts.css, style-library/, scripts/styles/, new woff2s —
  uncommitted at handover). Don't sweep those into a v3 commit.
- `build-deploy.sh` re-stamps `apps/figma-app/version.js` and re-syncs
  `apps/figma-app/themes.css` from `design/themes.css` on every run — the
  figma-app copy had drifted STALE in HEAD, so the first build shows a big
  diff there. That's the script working as designed, not v1 logic touched.
- Headless 3D needs `--use-gl=angle --use-angle=swiftshader` (already in
  both suites); first reduced-motion render ~50–80ms (scene compile),
  steady-state ≤6ms — don't judge the budget off frame #1.
