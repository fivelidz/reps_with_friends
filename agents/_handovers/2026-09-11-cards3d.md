## Gotchas hit
- **Headless + loaded machine ≠ idle machine**: SwiftShader frames starve under load (this box hit load-avg 40+ from unrelated sessions) → dt clamps at 0.06 → sim-time runs ~half speed → fixed-sleep settle checks flake. The runner-advance e2e now POLLS to the expected position (same assertion). If suites flake on timing: check `uptime` first, not the code.
- **WebGL canvas pixel-samples read blank between frames** (buffer clears after composite) — sample inside a rAF that registers AFTER the render loop's rAF.
- The played card leaves `r.cards` (so its tween must be driven by `course._flying` — forgetting this = card hangs mid-air, no burst, `lastPlay` never set).
- `cards3d.js` imports `three` via the page importmap — any host page needs the same importmap (all RWF pages have it).
- Never dispose `__rwfShared` assets in a host teardown — course.dispose already skips them.
