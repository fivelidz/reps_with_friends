Add RWF to Slack

Five minutes, one workspace, zero cost. The bot runs on our infra — you just install the app.

1

Create the app from our manifest

Go to api.slack.com/apps → Create New App → From an app manifest → pick your workspace → paste this:

loading…

Any workspace works — including a free one made just for testing.

2

Install & grab your tokens

  1. Install to Workspace (app settings → Install App) → allow
  2. Copy the Bot User OAuth Token (xoxb-…)
  3. Toggle Socket Mode ON → copy the App-Level Token (xapp-…)
3

Generate your install link

Paste the Client ID (app settings → Basic Information — starts 1… . …) and we'll build the one-click Add to Slack link you can share with any workspace admin:

Add to Slack ↗

Anyone in your org with permission can click it — Slack walks them through the install.

4

Bring the bot online

We run the bot; you just need it running when your crew plays:

cd apps/bot-slack
SLACK_BOT_TOKEN=xoxb-… SLACK_APP_TOKEN=xapp-… bun main.ts --live

Then in any channel: /rwf new → /rwf join casual → /rwf start → /rwf log pushups 25
