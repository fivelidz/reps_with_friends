# RWF App — phone-first PWA (lane 02)

Home base: profile, crew, match creation, live standings, rep logging, taunts,
charity pot — and the link-to-chat flow that pulls the bots into an existing
group chat. Vanilla TS + handcrafted CSS on `@rwf/game-core`. No framework,
no deps.

## Build & run

```sh
bun build apps/web/src/main.ts --outdir apps/web/dist --minify
bun serve.ts            # → http://localhost:4173/app
```

`dist/index.html` is a static shell (not generated by the build — bun only
emits `main.js` + `main.css` into `dist/`). It references assets with absolute
`/app/...` paths because the page is served at `/app` without a trailing
slash (relative URLs would resolve against `/`).

## Structure

```
src/
  main.ts        entry — hash router (#/onboard #/ #/new #/link/:id
                 #/match/:id #/result/:id #/profile), bottom nav, scroll+anim
                 preservation across re-renders
  engine.ts      re-export of packages/game-core (single import point)
  state.ts       AppState + localStorage (rwf.state.v1) + all actions
  ui.ts          el() DOM helper, inline SVG icons, toasts, clipboard
  data.ts        exercises, charities, demo crew, canned taunts, tier info
  styles.css     all app CSS; @imports ../../design/tokens.css (never forks)
  screens/       onboard · crew · home · newmatch · link · match · result ·
                 profile
test/
  flow.ts        headless state/engine flow test (bun test/flow.ts)
  browser.ts     real-Chromium CDP walk of the full UI (bun test/browser.ts)
dist/            build output + static shell (index.html, manifest, icon)
screenshots/     captured walkthrough (Aug 2026)
```

## Notes

- **State**: `localStorage["rwf.state.v1"]` — `{me, crew, matches, pots}`.
  The engine is pure; every mutation goes through `state.update()` which
  clones → mutates → persists → re-renders.
- **Demo crew**: the link screen has an "ADD DEMO CREW" button (Sam/Priya/Dex).
  While a match view is open, demo crewmates log reps on a 7s timer so
  standings move live. Real crew arrive via the chat bots (lane 01).
- **Camera verify**: button exists, logs `verified:false` + "coming soon"
  toast — pose counting is lane 07.
- **Fonts**: Space Grotesk `@font-face` lives in `dist/index.html` with an
  absolute `/design/fonts/sg-var.woff2` URL (bun's CSS bundler can't leave
  absolute `url()`s unresolved at build time).
- **Reset**: Profile → "RESET APP DATA" (double-tap to confirm).
