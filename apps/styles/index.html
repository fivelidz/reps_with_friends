05 · Checks — computed styles + WCAG, live in this page

not run yet

Reads each frame's computed tokens (same-origin), then recomputes WCAG ratios in-browser. The offline source of truth is scripts/styles_contrast.py; the headless walk is apps/styles/e2e.mjs.

How it works — the portable library design/style-library/ (one file per kit + base.css + index.css + README) holds twenty-one [data-theme] kits over the slot contract in design/tokens.css; design/themes.css imports it and adds the RWF app bindings. The ◈ kits are mined from the founder's live sites — palette + type + structure, verbatim from their CSS: five originals (tokens + component feel) and nine material kits including the new Sports Poster as full languages (tokens + component CSS + type + motion for the fg-* library and the bd-* board app). Load both stylesheets, set <html data-theme="…">, and every token consumer flips. The v2 app ships the same skins: /v2 → theme row.

Fonts vendored in design/fonts/ (Google woff2, latin subset, offline) · no new dependencies · themes are opt-in — the default product skin stays Lime Athletic.
