The power-up art system

21 cards × 7 named styles, all procedurally drawn — real vector symbols (no emoji) in the sports-poster language: star-bursts, speed lines, halftone shading, offset print misregistration, thick keylines. The "local media studio": canvas paths rendered to SVG + PNG by a build script, committed assets — no runtime generation, no image API.

Every card shows front + back, its full engine data (effect, target, expiry, counters — read live from apps/sot-engine.js, never hardcoded), and a 💛 like / 💬 note pair saved to this device so founder feedback ships with the deck.

Built for site/powerup-art/ (the generator) · rendered into site/powerup-art/gen/ · reviewed here at /powerups. The 3D card faces (v3) and the v4 app chips already wear the Poster master style.
