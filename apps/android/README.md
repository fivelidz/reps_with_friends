# Reps With Friends — native Android app

A minimal WebView shell around **https://rwf.qalarc.com/figma-app**
(package `com.qalarc.repswithfriends`, label "Reps With Friends").

- Plain `android.app.Activity` + framework Material dark theme + WebView —
  **zero external dependencies** (no Compose, no AndroidX).
- Back button → `webView.goBack()` (in-app navigation). Links to
  `rwf.qalarc.com` stay in the WebView; everything else opens externally.
- JS + DOM storage + cache enabled. Status/nav bar `#0a0b0d`.
- Offline fallback: `app/src/main/assets/offline.html` (dark, lime Retry
  button bridged to a reload via `window.Android.retry()`).
- Launcher icon: lime dumbbell (the site glyph) on dark — generated by
  `scripts/make_icons.py` (adaptive XML + PNG mipmaps for all densities).

## Build

```bash
cd apps/android
./gradlew :app:assembleDebug
# -> app/build/outputs/apk/debug/app-debug.apk
```

Toolchain: Gradle 8.7 wrapper, AGP 8.5.0, Kotlin 1.9.24, JDK 17,
SDK at `~/Android/Sdk` (see `local.properties`). Scaffolding inherited from
the known-good `~/projects/phone_projects/qalarc-explorer` project.

## Install on the Redmi (HyperOS)

`adb install` pops a 6-second auto-denying MIUI dialog — use the proven
helper (see `~/projects/phone_projects/AGENT_GOTCHAS.md`):

```bash
bash ~/projects/phone_projects/camera_system/install_with_miui_dialog.sh \
  apps/android/app/build/outputs/apk/debug/app-debug.apk
```

## Launch / verify

```bash
adb shell monkey -p com.qalarc.repswithfriends 1
adb exec-out screencap -p > /tmp/rwf.png
```
