Every sound the app makes, tappable

These are the live app sounds. This page runs the exact WebAudio synthesis module the apps play — same catalogue, same envelopes, same combo-climbing log pitch. There are no audio files anywhere in the repo; every sound is generated at the moment you tap.

Mute is shared with the app (localStorage rwf.sfx.muted).

Source: apps/figma-app/sfx.js (the live module) defensively copied to apps/sfx-demo/sfx.js — same catalogue, same synth; only the app-DOM wiring differs. The v2 board app calls window.rwfSfx?.play(name) — this page exposes the identical global.
